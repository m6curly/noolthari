Damage & Defect Return Policy

NOOLTHARI™ currently supports returns only for verified damage or manufacturing defects associated with an delivered order.

Eligible returns

A return request may be submitted when the saree is received with visible damage, a material defect or another issue that reasonably falls within the damage/defect category.

Not automatically eligible

Change-of-mind purchases, personal preference, ordering the wrong product, colour preference or other non-defect reasons are not automatically eligible for return.

When to request a return

Return requests are available after the related order has been marked as delivered. The relevant order item should be selected when submitting a request.

Evidence

Photos or other evidence may be requested to help verify the reported damage or defect. Providing clear photographs of the saree and the affected area can help with the review process.

Review process

Every return request is subject to review. Submission of a request does not by itself guarantee approval. NOOLTHARI™ may review the order information, reason, description and supporting evidence before deciding the appropriate resolution.

Resolution

When a return is approved, the applicable return, refund or replacement process will be communicated based on the circumstances of the order and the available resolution.

Submit a return request

Eligible customers can submit a damage or defect request through their account.
